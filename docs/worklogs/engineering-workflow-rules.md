- 날짜: 2026-08-13
- 브랜치: `codex/engineering-workflow-rules`
- 목표: 이후 기능·성능 작업의 브랜치, 기록, 검증, PR, 롤백 규칙을 저장소 단일 원본으로 고정한다.

## 기준선과 가설

- 기준선: 저장소 루트에 공통 에이전트 작업 규칙과 일반 작업 일지 양식이 없었다.
- 가설: 브랜치·측정·문서·검증 순서를 명문화하면 성능 실험 결과와 롤백 판단의 재현성이 높아진다.
- 성공 기준: `AGENTS.md`와 표준 일지 양식이 Git/PR·성능 측정·개인정보·검증·롤백 규칙을 모두 명시한다.

## 변경 내용

- 저장소 루트 `AGENTS.md`에 공통 작업 규칙을 추가했다.
- `docs/worklogs/_template.md`와 이 작업의 첫 일지를 추가했다.

## 검증

- 실행 명령: Markdown 링크·형식 검토, `git diff --check`.
- Before → After: 규칙 파일 0개 → `AGENTS.md` 1개, 일반 작업 일지 양식 0개 → 1개.

## 판단과 롤백

- 판정: 규칙 문서만 추가하며 런타임·배포 자산·사용자 기능에는 영향이 없다.
- 위험: 규칙이 실제 작업 흐름과 불일치할 수 있다.
- 롤백 조건: 브랜치·PR 절차 또는 성능 문서 경로가 저장소 운영 방식과 충돌하면 해당 항목을 다음 문서 PR에서 정정한다.
